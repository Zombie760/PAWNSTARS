Napsterization Model

Conscious disruption doctrine: Build illegal → Grow → Face enforcement → Capture → Monopoly

Doctrine: Conscious strategy: Build illegal/unregulated product -> Grow massive volume before enforcement -> Face enforcement (fine/Wells notice) -> Negotiate settlement -> Regulatory capture -> Legitimized monopoly

Origin

Napster (1999-2001): Illegal P2P -> 80M users -> RIAA lawsuits -> Bankruptcy -> iTunes/Spotify legitimized model

Key Insight: Napsterization is the Stage 5 mechanism: Regulatory capture through conscious disruption. The fine/Wells notice is not a penalty - it's the entrance fee to the legitimized monopoly.
